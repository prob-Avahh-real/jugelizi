# jugelizi

A knowledge-sharing app — "chestnut" tips (little nuggets of wisdom) across categories like programming, design, lifestyle, learning, and trivia.

## Tech Stack

- Expo SDK 56
- React Native 0.85.3
- React 19.2.3
- React Navigation v7 (bottom-tabs + native-stack)
- TypeScript

## Getting Started

```bash
npm install
npx expo start
```

## Scripts

- `npm start` — Start Expo dev server
- `npm run android` — Start for Android
- `npm run ios` — Start for iOS
- `npm run web` — Start for web
- `npm test` — Run tests

## Project Structure

```
jugelizi/
  src/
    types/        # TypeScript type definitions
    theme/        # Colors, spacing, font size constants
    data/         # Mock data
    screens/      # Screen components (FeedScreen, DetailScreen, ProfileScreen)
    navigation/   # Navigation configuration
  __tests__/      # Test files
```
